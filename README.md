# cleanfont

Clean structured JSON font payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/cleanfont/

## Install / run

```bash
git clone https://github.com/theworker02/cleanfont.git
cd cleanfont
node src/cli.js
node --test
```
